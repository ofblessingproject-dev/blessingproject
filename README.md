# Blessing Project - 공식 홈페이지

본 프로젝트는 영상 제작 전문 크리에이터 그룹 'Blessing Project'의 공식 홈페이지 소스 코드입니다. 
빠르고 가벼운 HTML, CSS, JavaScript로 이루어진 **정적 웹사이트(Static Website)**입니다.

## 📂 파일 구조
- `index.html` : 메인 페이지 (Hero 섹션, 핵심 비전 소개, 최신 작업물)
- `portfolio.html` : 포트폴리오 페이지 (Original IP 및 단편 등 유튜브 임베드 영상 목록)
- `contact.html` : 연락처 페이지 (이메일 및 기타 협업 문의)
- `styles/main.css` : 전체 사이트의 디자인(프리미엄 다크 테마) 및 레이아웃, 반응형 속성 정의
- `scripts/main.js` : 모바일 메뉴 토글 제어 및 부드러운 스크롤 페이드인(Fade-in) 애니메이션
- `serve.sh` : 로컬 테스트용 서버 실행 스크립트 (Mac/Linux 전용)
- `blessing_project_demo.mp4` : 사이트 실제 구동 데모 영상

## ✏️ 커스터마이징 (수정 방법)
홈페이지의 내용이나 영상을 바꾸고 싶을 때는 코드를 잘 몰라도 HTML 파일을 메모장이나 코드 편집기(VS Code 등)로 열어서 직관적으로 수정할 수 있습니다.

1. **텍스트 수정**:
   - `index.html`, `portfolio.html`, `contact.html` 파일을 열고, 인사말이나 회사 정보 등 원하는 텍스트를 찾아 변경 후 저장하면 즉시 반영됩니다.
   
2. **유튜브 영상 변경**:
   - 포트폴리오의 영상을 교체하고 싶다면 유튜브 영상 하단의 '공유' -> '퍼가기(Embed)' 버튼을 눌러 나오는 `<iframe src="https://www.youtube.com/embed/...">` 코드를 확인합니다.
   - HTML 파일 내의 기존 `<iframe src="...">` 부분을 찾아 새로운 주소로 교체해 주면 됩니다.

## 💻 로컬에서 확인하기 (테스트 방법)
유튜브 임베드 영상은 브라우저의 보안 정책상 내 컴퓨터에 있는 파일(`file:///...`)을 그냥 더블클릭해서 열게 되면 **오류(Error 153)**가 발생할 수 있습니다. 
정상적인 레이아웃과 영상 재생 확인을 위해서는 로컬 서버를 통해 열어보는 것을 권장합니다.

- **Mac 사용자의 경우**:
  터미널을 열고 소스 코드가 저장된 폴더로 이동한 뒤, 아래 명령어를 입력하여 서버를 엽니다.
  ```bash
  python3 -m http.server 8000
  ```
  (또는 동봉된 `./serve.sh` 스크립트를 실행해도 됩니다.)
- 이후 브라우저에서 `http://localhost:8000` 으로 접속하면 사이트가 정상적으로 구동됩니다.

## 🚀 호스팅 (웹사이트 런칭 방법)
이 홈페이지는 백엔드 서버(DB)가 따로 필요 없는 정적 웹사이트이므로, 외부의 **무료 정적 웹 호스팅 서비스**를 통해 개인 도메인을 붙여 매우 쉽고 경제적으로 런칭할 수 있습니다.

**추천 호스팅 플랫폼:**
1. **Vercel / Netlify (무료/가장 추천)**: 개발자들에게 가장 사랑받는 플랫폼입니다. GitHub에 코드를 올려두고 연동만 하면 화면 갱신 및 보안 인증서(HTTPS) 발급, 전 세계 CDN 설정이 자동으로 처리됩니다.
2. **GitHub Pages (무료)**: 소스 코드를 GitHub에 업로드하고 Pages 기능을 켜기만 하면 즉시 무료로 웹에 배포할 수 있습니다.
3. **AWS S3 (유료 트래픽)**: 실무에서 많이 쓰이는 전통적이고 안정적인 클라우드 호스팅 방식입니다.

**오리지널 도메인 연결**:
가비아나 호스팅케이알 등에서 기업의 도메인(예: `blessingproject.com` 등)을 구입한 뒤, 위에서 선택한 호스팅(예: Vercel) 측에 해당 도메인을 등록해주면 방문자들이 그 도메인을 통해 웹사이트에 접속할 수 있게 됩니다.
